# Miru(ミル)— データ可視化ツール

名前は「見る」から取りました。

JSONL / CSV などのファイルをブラウザで読み込み、項目を選んでグラフを作る汎用ツールです。

- HTML / CSS / JavaScript だけで動きます。ビルドもサーバー側の処理も不要です。
- ファイルはブラウザの中だけで処理され、サーバーへは送信されません。
- 必要なライブラリはすべて `vendor/` に入っているので、外部との通信は発生しません。閉域網でもそのまま使えます。
- 画面デザインは[デジタル庁デザインシステム](https://design.digital.go.jp/)の HTML 版コードスニペットを使っています。

## 配置方法

このフォルダを丸ごと、Web サーバー(nginx / Apache / IIS など)の公開ディレクトリにコピーし、`index.html` を開いてください。

- サーバー側で特別な設定は要りません。静的ファイルとして配信できれば動きます。
- `index.html` をダブルクリックして `file://` で開いても動きます(動作確認用)。
- `tests/` は開発用のテストなので、配置しなくてもかまいません。

対応ブラウザ: Microsoft Edge / Google Chrome / Firefox / Safari の最新版

## 使い方

1. **データを読み込む**: ファイルを選択するか、点線のエリアにドラッグ＆ドロップします。
   - 対応形式: JSON Lines(`.jsonl` `.ndjson` `.log`)、JSON 配列(`.json`)、CSV、TSV
   - 文字コード(UTF-8 / Shift_JIS)と形式は自動で判定します。判定を誤った場合は「読み込み設定」で変更してください。
   - 各列の型(日時 / 数値 / カテゴリ / 文字列)と日時の書式も自動で判定し、「列の型と書式」に表示します。誤っていれば変更できます。
2. **グラフを作成する**: グラフの種類、X 軸、Y 軸(複数選択可)を選びます。設定を変えるとすぐに描き直されます。
   - **系列の分割**: カテゴリ列の値ごとに線や棒を分けます(9 件以上ある場合は上位 7 件と「その他」にまとめます)。
   - **集計**: 合計 / 平均 / 最大 / 最小 / 件数。X 軸が日時の場合は「時間の単位」(時・日・週・月・四半期・年度・年)を選べます。
   - **絞り込み**: 期間と、カテゴリの値で絞り込めます。
   - **表示オプション**: タイトル、西暦 / 和暦の表記、表示タイムゾーン、凡例の位置、欠測区間の扱い、縦軸を 0 から始めるかどうか。
3. **操作と保存**: ドラッグで左右に移動、Ctrl + ホイールで拡大・縮小、Shift + ドラッグで範囲を指定して拡大できます。「PNG 保存」でグラフを画像として、「CSV 保存」で表示中の(集計後の)データを保存できます。

サンプルデータは `sample/` にあります。

| ファイル | 内容 |
|---|---|
| `sample/monthly_wareki.csv` | 和暦の年月 × 地域別の月次データ(CSV、行の順番はばらばら) |

## 時系列データの扱い

日時と判断した列は内部でミリ秒単位の時刻に変換し、時刻の順に並べ替えてから描画します。ファイル内の行の順番は関係ありません。

**読み取れる表記の例**(全角数字も読み取れます)

| 種類 | 例 |
|---|---|
| 日時 | `2026-10-30T16:42:16+09:00`、`2026/10/30 16:42`、`2026年10月30日 9時30分`、`2026/11/16(月) 午後3:05` |
| 日付・年月・年 | `2026-10-30`、`20261030`、`10/30/2026`、`2026-11`、`2026年11月`、`2026年` |
| 和暦 | `令和8年11月`、`令和元年5月1日`、`R8.11.1`、`H31.4.30`、`令8.11` |
| 年度・四半期 | `2026年度`、`令和8年度`、`2026Q3`、`2026年第3四半期`、`令和8年度第1四半期` |
| UNIX 時刻 | `1793000000`(秒)、`1793000000000`(ミリ秒)。列名が `time` や `timestamp` などの場合のみ自動で判定します |

- **判定の仕方**: 列ごとに 1 つの書式を決めます。値の 90% 以上が同じ書式で読めた場合に、その書式で日時と判定します。読めなかった値は欠損として扱い、件数と例を警告で表示します。
- **和暦**: 明治から令和まで読み取れます。`平成31年5月1日` のように、その元号の期間外にあたる日付はエラーになります。年度は 4 月始まりとしています(「年度の開始月」で変更できます)。
- **一覧にない書式**: 「日時の書式」で「カスタム」を選び、`yyyy年M月d日 H時`、`gge年M月`、`yyyy-MM-dd'T'HH:mm` のように指定します。使える記号は y(年)、M(月)、d(日)、H(時)、m(分)、s(秒)、g(元号)、e(和暦の年)、Q(四半期)です。
- **タイムゾーン**: `+09:00` などの時差が付いた値は、その時刻のまま扱います。時差が付いていない値は「データのタイムゾーン」(初期値は日本時間)で解釈します。表示は「表示タイムゾーン」(初期値は日本時間)に揃えるので、閲覧する端末のタイムゾーン設定が違っても同じグラフになります。
- **粒度**: 秒・分・日・月などのデータの細かさを自動で判定します。集計の単位には、データより細かい単位は出てきません(月次データに「日ごと」は表示されません)。年・年度・四半期の単位で表示するときは、データの欠けている期間も軸に並べます。
- **欠測区間**: 点と点の間隔が通常の間隔(中央値)の 3 倍を超えるところは線を切ります。ログの収集が止まっていた期間が直線でつながり、データがあるように見えてしまうのを防ぐためです。倍率は表示オプションで変えられます。

## 構成

```
index.html            画面
css/app.css           レイアウト(色や文字の設定は DADS のトークンを使用)
js/datetime.js        日時・和暦・年度の解析と表示、期間の切り捨て
js/parser.js          文字コードの判定、JSONL / JSON / CSV / TSV の解析
js/schema.js          列の型の推定と値の変換
js/transform.js       絞り込み、集計、系列の分割
js/date-adapter.js    Chart.js の時間軸用アダプタ(表示タイムゾーンを固定する)
js/chart-view.js      Chart.js の設定の組み立て
js/app.js             画面の状態管理
vendor/               同梱ライブラリ(vendor/LICENSES.md を参照)
sample/               サンプルデータ
tests/                Node.js によるテスト(node --test tests/*.test.js)
```

```sh

```

Node.js 18 以上が必要です。`datetime` / `parser` / `schema` / `transform` は DOM に依存しないので、Node.js 上でそのままテストできます。
