Miruデータ可視化ツール

CSVファイル等をブラウザ内で読み込んでグラフを作成します。ファイルはサーバーへ送信されません。

1. データを読み込む

対応形式: CSV(.csv), TSV(.tsv), JSON Lines(.jsonl / .ndjson / .log), JSON 配列(.json)。文字コードは UTF-8 / Shift_JIS を自動判定します。

または、このエリア内にドラッグ＆ドロップ

      列の型と書式(自動判定結果)

      判定が誤っている場合は、型や日時の書式を変更してください。書式一覧にない日時は「カスタム」で yyyy年M月d日 H時 のように指定できます(y:年 M:月 d:日 H:時 m:分 s:秒 g:元号 e:和暦年 Q:四半期)。
